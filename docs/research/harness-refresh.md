Living record of `harness-guidance` (refresh mode) sweeps — the per-facet,
per-source state a run diffs against, so each sweep reports what
**changed** since the last one instead of rediscovering the whole `.claude/`
surface from scratch. Updated **in place** on every run, never as a new
dated file.

**2026-10-20 sweep** — sixth sweep, run by `/customize` right after it installed the `harness-extras` and `github` packs and back-ported baseline fixes #71, #82 and #150 into the root harness; five parallel Explore spokes, every repo-impact claim re-checked against the cited file.
