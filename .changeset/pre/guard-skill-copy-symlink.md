In adopt mode, installing the `/customize` skill no longer writes through a symlink (fresh mode now refuses a symlinked path before writing anything, see its own changeset) and never removes or overwrites anything the project owns (fresh mode with `--force` still replaces an existing skill copy). Presence under `.claude/skills/customize/` is decided with `lstat`: an existing entry there (a differing copy, a project file under one of the skill's file names, including a data file the CLI is not permitted to read (any other read error stops the install with the underlying error instead of guessing), a directory, or a symlink, dangling or not), or a `.claude`, `.claude/skills` or `.claude/skills/customize` that is a symlink or not a directory, sends the skill to `.groundwork/customize/` instead, and the CLI says why and what to do next (Claude Code does not load that copy). A symlinked `.groundwork` or `.groundwork/customize` still stops the install before the skill is written. `SKILL.md` is written last, and if a write fails, including a partial write, the CLI makes a best-effort attempt to remove every file it created and says which ones it could not remove (a `SKILL.md` it could not remove is named, with the advice to delete it by hand), so a half-installed skill is normally not left for Claude Code to load; files that `--force` replaced earlier in the same run are not restored; a half-finished install left under `.claude/skills/customize/` is completed on the next run only when every leftover file matches this CLI version's copy byte for byte, and is otherwise left alone. Errors from the install say what happened and carry their cause.

In fresh mode a failed skill install now says the project was written but `git init` and `pnpm install` did not run (`pnpm install` was skipped anyway under `--skip-install`), and how to recover: re-run with `--fresh --force`, plus your original `--name`, `--pack` and `--skip-install` flags. A byte-identical `--force` re-run leaves the existing skill alone and reports that it is already up to date.
