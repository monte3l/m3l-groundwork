The `harness-extras` pack's `guard-readonly-bash` no longer blocks ordinary read-only commands and blocks more real writes. A `>` inside a quoted string (`grep "=> {" src`) is not treated as a redirect, and the read-only forms of `git branch`, `git worktree list`, `git stash list|show`, `git config --get` and `git tag -l` are allowed. `git branch` is now an allowlist, so an unrecognised flag blocks. `pnpm format`, `pnpm lint --fix`, `prettier --write`, `eslint --fix` (also through `pnpm exec`, `pnpm dlx`, `npx` and `npm exec`), and git config keys or environment variables that run a command (`core.pager`, `GIT_EXTERNAL_DIFF`, …) are blocked. The compaction-handoff hooks now root at the hook payload's `cwd` instead of `CLAUDE_PROJECT_DIR`, so they record the right checkout inside a worktree. The handoff file is keyed by session (`tmp/compact-handoff-<session_id>.json`), written atomically, and a starting session only recovers another session's handoff that is between 10 minutes and 24 hours old. `git tag` is an allowlist like `git branch` (a value-taking flag can no longer swallow `-l`), version-pinned tools (`npx prettier@3 --write`) are judged as the tool, `eslint --fix-dry-run` is allowed, and a `|` or `;` inside a quoted pattern no longer splits the command.
